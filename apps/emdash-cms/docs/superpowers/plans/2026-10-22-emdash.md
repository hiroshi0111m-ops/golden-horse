> **For agentic workers:** Execute directly in this session with superpowers:executing-plans; do not delegate.

**Goal:** Install the user's Astro + EmDash example as a working independent application.
**Architecture:** Standalone Node SSR application; EmDash owns SQLite schema and management UI; Astro renders published posts through its live loader.
**Tech Stack:** Node 24, current compatible Astro, EmDash, React, SQLite.
**Spec:** `../specs/2026-10-22-emdash-design.md`

## Global Constraints

- Preserve existing GOLDEN HORSE source and checkpoints.
- Do not commit credentials, content databases, uploaded media, build output or node_modules.
- The owner must register their own administrator passkey.

## Review Focus

- Empty content: a useful empty state instead of a broken page.
- Unauthenticated management: no access to private content or configuration.
- Query failures: fail explicitly instead of presenting a false empty result.
- HTML in titles: Astro escapes text.
- Persistence: use a durable filesystem when deploying Node; static hosting is insufficient.
